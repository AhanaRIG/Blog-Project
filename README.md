# Blogging Web Application

## Description
A full-stack blogging web application that allows users to create and manage blog posts securely. The application supports user authentication and CRUD operations on posts, enabling users to sign up, log in, publish content, update existing posts, view their own posts, and delete posts. Appwrite is used as the backend service for authentication and database management.

## Features
- User authentication (Sign up, Login, Logout)
- Create new blog posts
- Update existing blog posts
- Delete blog posts
- View all posts created by the logged-in user
- Secure access to user-specific content
- Responsive user interface

## Tech Stack
- Frontend: HTML, CSS, JavaScript, React
- Backend as a Service: Appwrite
- Database: Appwrite Database
- Authentication: Appwrite Auth
- Version Control: Git, GitHub
